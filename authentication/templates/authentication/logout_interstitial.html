{% comment %} Logout interstitial. Logging out of Learn has to log the user out of the sibling applications too -- MITx Online, studio, Open edX -- because each keeps its own APISIX gateway session on its own parent domain, and Learn's Set-Cookie cannot reach them (hq#12763). Open edX already knows the full list (IDA_LOGOUT_URI_LIST) and fans a logout out to it by rendering one hidden iframe per application, so this page frames Open edX's logout page rather than duplicating that list here. Framing it, rather than redirecting to it, keeps the user on learn.mit.edu. The frame is driven from JS rather than a static src so the load handler is attached before the request starts. {% endcomment %} Signing out
